This skill provides guidelines for analyzing data engineering SaaS products (e.g. DBeaver, PopSQL, Mode, SQLPad, SQLGlot), reverse-engineering utility workflows, and positioning DataMaster Pro's zero-server privacy advantage.

- Highlight DataMaster Pro's asymmetric advantage: 100% in-browser WASM processing vs cloud tools that require uploading enterprise CSV data to remote database servers.

### 2. Micro-SaaS Utility Benchmarking
- Evaluate onboarding friction, dataset file limits, and multi-dialect accuracy across DDL generation, schema diffing, and statistical profiling tools.

### 3. Tactical Roadmap Recommendations
- Provide dense, actionable product feedback to maintain DataMaster Pro's fast, developer-first experience.
