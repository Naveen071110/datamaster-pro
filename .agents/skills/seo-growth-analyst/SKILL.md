# Technical SEO & Growth Analyst Skill

This skill provides optimization standards for technical search engine optimization, meta tags, social sharing cards, and conversion copywriting for DataMaster Pro.

## 🎯 Core Optimization Checklist

### 1. Metadata & OpenGraph Standards (`index.html` & `LandingPage.tsx`)
- Title Tag: `DataMaster Pro — Privacy-First Developer Utility Suite for Data Engineering`
- Meta Description: Compelling, keyword-rich summary of in-browser WASM SQL sandbox, multi-dialect DDL generator, statistical profiler, and schema diff tools.
- OpenGraph & Twitter Cards: `og:type="website"`, `og:title`, `og:description`, `twitter:card="summary_large_image"`.

### 2. Schema.org JSON-LD Structured Data
- Include `<script type="application/ld+json">` with `WebApplication` schema, `operatingSystem: "All"`, `applicationCategory: "DeveloperApplication"`, and free pricing offer details.

### 3. Semantic Hierarchy & Accessibility
- Strict single `<h1>` tag per page hierarchy (`LandingPage.tsx`, tool pages).
- All interactive buttons and links MUST have accessible `aria-label` attributes and keyboard focus styles.
